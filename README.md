# LinkTracker

Telegram-бот, который отслеживает изменения на веб-страницах и информирует пользователя о них.

## Запуск

1. Клонировать репозиторий и перейти в корень проекта.
2. Создать файл `.env` с переменной `APP_TELEGRAM_TOKEN` (токен от [@BotFather](https://t.me/BotFather)).
3. Собрать проект: `make build`.
4. Запустить: `make run-bot`.

Для отладочных логов — задать `logging.mode: "DEBUG"` в `config.yaml`.
